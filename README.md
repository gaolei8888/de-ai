# 点睛 de-ai

**AI 生成，点睛完成。**

项目定位：多模态 AI 作品精修引擎，覆盖文字、语音、影像、软件 UI。当前只实现文本静态规则、HTML 静态规则和本地 Playwright UI 审查 CLI；语音、视频和自动修复仍在规划中。

开发指南：[本地运行](docs/DEVELOPMENT.md) · [界面点睛](docs/UI_AUDIT.md) · [多模态设计](docs/MULTIMODAL_PRODUCT_DESIGN.md)

面向真实作者表达的 AI 内容质量引擎（Writing Quality Engine）。

## 定位

本项目不以检测“是否由 AI 撰写”为目标，而以**保留作者原意、消除模板化写作、核验事实与改进内容质量**为核心。可独立运行，提供 API 供 dc-octo、DCT、DCO/DCV 调用。

## 首期能力（MVP）

1. **LLM Voice 审查**：指出空洞套话、机械排比、重复、含混结论，标明原文位置及理由。
2. **观点保真编辑**：区分作者明确观点、事实性陈述和待核验主张；改写不得擅自增加事实或更改结论。
3. **可解释修改**：原句、建议、依据和差异对照，用户决定是否接受。
4. **作者风格档案**：从经授权且作者认可的文本生成偏好，支持覆盖和删除。
5. **事实与引用检查**：不能核验的主张标为待核验；不生成虚构引用。

## 实施顺序

- P0：文本导入、规则+模型审查、分项报告、可选择改写与 diff、回归测试。
- P1：作者风格档案、中文/英文风格支持、质量评价集。
- P2：REST API、dc-octo 发布前审核集成、DCT / DCO / DCV 适配。

## 设计原则

- 优先提供具体可操作的写作反馈，不宣称可以可靠检测 AI 作者身份。
- 不以绕过 AI 检测器为优化目标。
- 任何自动修改可追溯、可撤回；事实核验与语言润色分开。
- 默认不保存用户原文；存储作者资料应取得明确授权。
- MVP 可通过外部 LLM API 实现，无需专用 GPU。
